\# Multi-Office Network Design



> A secure two-office network architecture designed around routed connectivity, firewall protection, managed switching, wireless access, and site-to-site VPN communication.



\## Overview



This project presents a multi-office network design connecting two office locations through secure network infrastructure.



The design covers the existing network environment, proposed office networks, inter-office connectivity, security controls, wireless access, and implementation considerations.

!\[Overall Network Architecture](diagrams/overall-network-architecture.png)



\## Key Components



\- Cisco edge routers

\- Cisco ASA firewalls

\- Managed Layer 2 switches

\- Wireless access points

\- Wired workstation connectivity

\- Network printers

\- Video conferencing connectivity

\- Internet/WAN connectivity

\- Site-to-site VPN

\- Structured Ethernet cabling
